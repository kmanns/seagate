# Seagate Demo Theme Refresh

## Phase 1: Requirements

- Re-theme the Adobe Commerce EDS boilerplate to feel like a modern Seagate-inspired B2B storefront.
- Use the visual direction from `AGENTS.md`: modern, cutting-edge, shoppable, accessible.
- Keep the implementation storefront-only and avoid risky backend or drop-in logic changes.
- Focus on global theme tokens and the most visible shared blocks first.

## Implementation Focus

- Global tokens, typography, buttons, section spacing, and default content styling
- Header, hero, cards, columns, carousel, and footer visual refresh
- Preserve upgrade-friendly structure and existing block behavior
